# Сохранённые сессии

Политика от 13 октября 2026: все действия основного приложения используют
профиль аккаунта `browserStoreID`. Перед обычным действием проверяется текущая
личность; при активной сессии пароль и 2FA повторно не отправляются. Отсутствующая
или истёкшая сессия допускает обычный вход. Неизвестный ответ/сбой сервера
останавливает действие и не считается признаком выхода из аккаунта.

Проверка подписки, исходная смена почты/пароля/2FA, вход по ссылке и импорт
CodexAcc используют сохранённый профиль. После изменения доступов отдельный
чистый вход остаётся обязательным доказательством нового пароля или ключа;
подтверждённая сессия сохраняется для следующих действий и перезапуска приложения.
Переносятся только защищённые действующие cookies OpenAI/ChatGPT между сессиями
одного проверенного аккаунта и одного прокси. Ошибка сохранения возвращает
прежние cookies. При смене email дополнительно проверяется неизменный ID пользователя.

Автоматический выход из всех сеансов после смены 2FA отменён этой политикой.
Исторический документ `2026-09-01-logout-all-after-2fa-design.md` описывает прежнее
поведение. Явная команда нового входа для восстановления остаётся отдельным
действием; незавершённые этапы смены 2FA не теряют исходную сессию.

Импорт CodexAcc сначала проверяет сохранённый вход, в том числе последний
проверочный вход после смены пароля. URL авторизации, state, PKCE и callback
остаются неизменными. На финальном экране выбирается единственная «Личная
учётная запись» / Personal account с точным email, затем нажимается продолжение.
Несколько личных вариантов, чужой адрес или неизвестная форма требуют ручного
действия; рабочая область организации автоматически не выбирается.

Форма OpenAI с названием в `aria-label` и прозрачным переключателем распознаётся
по видимой подписи личной области; декоративный аватар не входит в её название.
На загрузку выбора аккаунта и области отводится до 30 секунд без ручного продолжения.

Новый импорт засчитывается только после подтверждения CodexAcc с тем же email.
Успешный клик в браузере сам по себе не считается завершённым импортом.
