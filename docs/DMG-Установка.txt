GPT Account Manager — установка

Требования: macOS 14 Sonoma или новее; Mac с Apple Silicon либо Intel.

1. Откройте DMG и перетащите GPT Account Manager в папку Applications.
2. Извлеките образ и запустите приложение из папки «Программы».
3. Для автоматического получения кодов откройте «Почта Mail.ru», укажите свой
   основной адрес, сохраните его и войдите в этот же ящик в окне приложения.
   Нажмите «Проверить чтение». Сеанс почты сохранится на вашем Mac.
4. Добавьте свои iCloud-алиасы в «Базу почт». Их письма должны пересылаться
   в подключённый ящик Mail.ru. Прокси добавляются отдельно в разделе прокси.

В образ не включены сохранённые аккаунты, сессии браузера, база адресов
и персональные настройки автора. На новом Mac приложение создаёт свои данные.
Установка поверх существующего приложения использует уже сохранённые данные.

Сборка подписана локальной ad hoc подписью, без Developer ID и нотарификации
Apple. macOS может заблокировать первый запуск. Разрешайте запуск через
«Системные настройки» → «Конфиденциальность и безопасность» только если
доверяете отправителю. Не отключайте защиту macOS целиком.

Для функции «Импорт в CodexAcc» отдельно требуется совместимый CodexAcc.
Node.js и отдельный браузер не требуются для основного интерфейса приложения.
