# Прокси

При первом запуске список пуст. Добавьте адреса или HTTPS-источник списка в разделе «Прокси».

## Использование

- «Использовать прокси» включает случайный выбор для новой регистрации. Перед
  созданием черновика выбранный адрес проверяется заново. Недоступные адреса
  пропускаются; при отсутствии рабочего регистрация не начинается напрямую.
- Выбранный адрес сохраняется в аккаунте. Основная сессия и отдельный проверочный
  вход используют тот же прокси. Восстановление временной сессии не теряет маршрут.
- Выключение действует для вновь открываемых сессий. Уже открытая сессия сохраняет
  свой маршрут до следующего открытия. Ранее созданные аккаунты без назначенного
  прокси используют прямое подключение.
- Личная почта Mail.ru остаётся в собственном соединении.

## Списки

Адреса можно добавлять строками, изменять, исключать из случайного выбора или
удалять. Ссылки на источники тоже редактируются. «Загрузить списки» объединяет
полученные адреса без дубликатов. Поддерживаются `host:port`,
`host:port:login:password` (HTTP по умолчанию), а также
`http://login:password@host:port`, `https://login:password@host:port`
и `socks5://login:password@host:port`. SOCKS4 не поддерживается;
результат импорта показывает число пропущенных строк.

Авторизация прокси сохраняется вместе с адресом и применяется как при проверке,
так и в браузере аккаунта. В списке и сообщениях пароль не показывается;
при редактировании доступны полные данные подключения.

«Проверить все» проверяет все строки четырьмя соединениями одновременно. Можно
проверить один адрес. Результат: доступность, задержка, внешний IP и время проверки.
Сначала запрос проходит через прокси к HTTPS API ipify. При ошибке программа
проверяет независимый HTTPS-сервис Cloudflare через тот же прокси.
Один сбой проверочного сайта не исключает адрес из выбора. Данные входа прокси передаются
самому прокси. Пароли и сессии ChatGPT и почты в проверке не участвуют.
Успех означает доступность этого HTTPS-сервиса через прокси,
но не гарантирует принятие IP сайтом ChatGPT.

## Хранение и ограничения

Настройки: Application Support/GPT Account Manager/proxies.json, права 0600.
Прокси по умолчанию выключены. Проверка одного адреса ограничена двумя попытками
до 15 секунд каждая,
загрузка источника — 20 секундами и 1 MiB. Случайный выбор проверяет не больше
12 кандидатов, начиная со случайных недавно доступных. Источники обновляются
только по кнопке. Удалённый адрес может вернуться при явной повторной загрузке
источника. HTTP использует CONNECT для HTTPS; HTTPS-прокси дополнительно требует
корректного TLS-сертификата самого прокси. Проверка сертификатов не отключается.

## Замена недоступного прокси

Закреплённый адрес сначала проверяется перед новой проверкой аккаунта и перед
возобновлением регистрации. Если он отвечает, адрес сохраняется. Если не отвечает,
приложение ищет другой включённый адрес, проверяет его и закрепляет за этим же
аккаунтом. Проверка вместе с подбором ограничена 12 кандидатами.

В карточке аккаунта и у остановленной регистрации есть «Сменить прокси» —
подбирает другой доступный адрес по запросу пользователя. Меняются только настройки
соединения: логин, пароль, TOTP, группа, этап и browserStoreID сохраняются.

При отсутствии замены прежняя привязка остаётся; прямое подключение не включается.
Автопереключение не повторяет уже отправленные формы и не меняет маршрут посреди
смены пароля/2FA/email. Если соединение пропало в ходе регистрации, после остановки
и «Возобновить» прокси проверяется заново.
