# Перенос аккаунтов между группами

9 октября 2026: источник перетаскивания перенесён с маленькой кнопки на всю
строку аккаунта через нативный item provider списка. Группы и «Без группы»
принимают перенос через зарегистрированную AppKit-зону заголовка. Зона
подсвечивается без перерисовки всего списка. В перенос передаются только ID.

Перенос вызывает существующее подтверждение и защищённую запись в хранилище.
Несколько выбранных аккаунтов передаются одним набором ID. Операция не меняет
пароли, ключи 2FA или браузерные сессии.

Проверка: 43 теста в 4 наборах прошли, включая настоящий провайдер строки
NSOutlineView, заголовки группы и «Без группы», отклонение постороннего текста,
одиночное/множественное выделение и сохранение группы. Release-сборка запущена.
Финальная проверка жеста мышью не подтверждена: инструмент управления окном
вернул `Computer Use server error -10005: noWindowsAvailable`.

Пакетный перенос: чтение общей строки NSPasteboard склеивало отдельные элементы
и ломало распознавание. Приёмник теперь читает каждый элемент отдельно,
объединяет ID без повторов и вызывает одно подтверждение для всей пачки.
Регрессия воспроизведена до исправления для 8 одиночных и повторяющихся пакетных
токенов. После исправления прошли 44 теста в 4 наборах, включая сквозную проверку
8 настоящих провайдеров строк NSOutlineView через один NSPasteboard в приёмник.
